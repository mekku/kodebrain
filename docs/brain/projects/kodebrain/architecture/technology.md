## Storage

| Role | Technology | Notes |
|---|---|---|
| Knowledge pages | Markdown + YAML frontmatter | Canonical format |
| Graph indexes | JSON (nodes.json, edges.json, file-index.json) | Derived from Markdown |
| File hashes | JSON (file-hashes.json) | SHA-256 per source file |
| History | Markdown + JSON (events.json) | Generated by timeline.py |

No database. No cache service. Everything is flat files.

## Dependencies

Kode Brain has zero runtime Python dependencies (`dependencies = []` in pyproject.toml). Scripts use only stdlib: `pathlib`, `json`, `re`, `argparse`, `hashlib`, `subprocess`.

## Key Libraries (stdlib only)

| Library | Used By | Purpose |
|---|---|---|
| `pathlib` | All scripts | File system traversal |
| `json` | compile_graph, timeline, harvest | JSON read/write |
| `re` | compile_graph, frontmatter | Wiki-link extraction, frontmatter parsing |
| `argparse` | harvest, compile_graph, timeline | CLI argument parsing |
| `hashlib` | harvest | SHA-256 file hashing |
| `subprocess` | hook.py | Platform config detection |
